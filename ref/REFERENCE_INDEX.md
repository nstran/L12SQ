## Ket Luan Tam Thoi

Hien co du media de chot:
- geometry cho `Hoa Lu`
- palette cho `rainy`
- palette cho `sunny`

Chua co du media de chot:
- full tileset chuan tung map
- sprite animation day du
- prop set day du cho moi map khac

## Rule Bo Sung Reference

Khi co them media moi:

1. Dat file goc vao `ref/raw/images` hoac `ref/raw/videos`
2. Khong ghi de file cu
3. Neu can crop/frame, dat vao `ref/derived`
4. Cap nhat file nay de danh dau media moi dung cho muc nao:
   `layout`
   `style`
   `sprite`
   `ui`
